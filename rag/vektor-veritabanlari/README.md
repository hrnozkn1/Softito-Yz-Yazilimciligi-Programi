# Vektör Veritabanları

ChromaDB ile vektör veritabanı kullanımı: embedding, index'leme, benzerlik araması.

## Kapsam

- Vektör veritabanı nedir? (vs geleneksel DB)
- Embedding oluşturma (sentence-transformers)
- ChromaDB ile index'leme ve kalıcı depolama
- Kosinüs benzerliği ile semantik arama
- Metadata filtreleme

## Çalıştırma

```bash
cd rag/vektor-veritabanlari
pip install -r requirements.txt
python vektor_db.py
```

## Kullanılanlar

`ChromaDB` · `sentence-transformers` · `NumPy`
