# Derin Öğrenme ile Görüntü Sınıflandırma

CNN ile görüntü sınıflandırma. CIFAR-10 veri seti üzerinde eğitim.

## Kapsam

- CNN mimarisi (Conv2D, BatchNorm, Pooling, Dropout)
- CIFAR-10 veri seti (uçak, araba, kuş, kedi, geyik, köpek, kurbağa, at, gemi, kamyon)
- Eğitim/değerlendirme grafikleri
- Confusion matrix
- Kaydedilmiş model ile inference

## Kurulum

```bash
cd goruntu-isleme/derin-ogrenme-goruntu
pip install -r requirements.txt
```

## Çalıştırma

```bash
python derin_goruntu.py
```

## Kullanılanlar

`PyTorch` · `torchvision` · `matplotlib` · `seaborn`
