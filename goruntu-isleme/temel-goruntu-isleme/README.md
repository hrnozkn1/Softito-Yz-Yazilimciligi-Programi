# Temel Görüntü İşleme

OpenCV ve scikit-image ile temel görüntü işleme teknikleri.

## Kapsam

- Piksel, kanal, boyut kavramları
- Renk uzayları (RGB, Grayscale, HSV)
- Histogram analizi ve eşitleme
- Bulanıklaştırma, keskinleştirme filtreleri
- Kenar tespiti (Canny, Sobel)
- Morfolojik işlemler (erozyon, genişleme)
- Kontur bulma

## Kurulum

```bash
cd goruntu-isleme/temel-goruntu-isleme
pip install -r requirements.txt
```

## Çalıştırma

```bash
python temel_goruntu.py
```

Kendi İstanbul fotoğraflarını `fotograflar/` klasörüne ekleyip `--resim fotograflar/istanbul.jpg` ile çalıştırabilirsin.

## Kullanılanlar

`OpenCV` · `scikit-image` · `NumPy` · `matplotlib`
