# 05 - LangChain

LCEL ile chain yapısı, memory ve tool kullanımı.

## Kapsam

- LCEL (| operatörü) ile chain oluşturma
- ConversationBufferMemory ile sohbet geçmişi
- Tool tanımlama ve kullanma (hesap makinesi, hava durumu)
- Agent ile çok adımlı karar alma

## Çalıştırma

```bash
cd llm/05-langchain
pip install -r requirements.txt
# .env dosyasına OPENAI_API_KEY ekle
python langchain_demo.py
```

## Kullanılanlar

`LangChain` · `OpenAI API`
