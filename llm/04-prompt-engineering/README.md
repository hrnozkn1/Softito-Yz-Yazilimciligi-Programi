# 04 - Prompt Engineering

Few-shot, Chain-of-Thought, system prompt tasarımı. OpenAI API ile çalışır.

## Kapsam

- Zero-shot vs Few-shot prompting
- Chain-of-Thought (CoT) ile adım adım akıl yürütme
- System prompt ile model davranışını şekillendirme
- Sıcaklık ve top-p parametrelerinin yanıta etkisi

## Çalıştırma

```bash
cd llm/04-prompt-engineering
pip install -r requirements.txt
# .env dosyasına OPENAI_API_KEY ekle
python prompt_engineering.py
```

## Kullanılanlar

`OpenAI API`
