# COPOD — Anomali Tespiti

Copula tabanlı anomali tespiti. Özellikler arası bağımlılık yapısını modelleyerek olasılıksal skor üretir.

## Çalıştırma

```bash
cd anomali-tespiti/copod
pip install -r requirements.txt
jupyter notebook
```

## Kullanılanlar

`PyOD` · `scikit-learn` · `NumPy` · `matplotlib`
