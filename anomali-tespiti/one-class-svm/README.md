# One-Class SVM — Anomali Tespiti

Normal veriyle eğitilip, normal bölgenin dışına düşenleri anomali olarak işaretleyen kernel tabanlı algoritma.

## Çalıştırma

```bash
cd anomali-tespiti/one-class-svm
pip install -r requirements.txt
jupyter notebook
```

## Kullanılanlar

`scikit-learn` · `NumPy` · `matplotlib`
