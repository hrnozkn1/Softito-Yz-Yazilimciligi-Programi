# Isolation Forest — Anomali Tespiti

Isolation Forest, anormal noktaları erken izole etme prensibine dayanan bir anomali tespit algoritmasıdır.

## Kapsam

- Algoritmanın çalışma prensibi
- Sentetik veriyle anomali tespiti
- Kontaminasyon oranı ayarı
- Görselleştirme (2B ve 3B)
- Gerçek veri seti uygulaması (kredi kartı)

## Çalıştırma

```bash
cd anomali-tespiti/isolation-forest
pip install -r requirements.txt
jupyter notebook
```

## Kullanılanlar

`scikit-learn` · `NumPy` · `matplotlib` · `seaborn`
