# Anomali Tespiti

Isolation Forest, One-Class SVM ve COPOD algoritmaları ile anomali tespiti projeleri.

| Proje | Algoritma | Yaklaşım |
|-------|-----------|----------|
| [Isolation Forest](isolation-forest) | Ağaç tabanlı | Erken izole etme prensibi |
| [One-Class SVM](one-class-svm) | Kernel tabanlı | Normal bölge sınırı öğrenme |
| [COPOD](copod) | Olasılıksal | Copula teorisi ile bağımlılık modelleme |

**Teknolojiler:** `scikit-learn` · `PyOD` · `NumPy` · `matplotlib`
